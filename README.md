# 🪙 Koopeika

**Конвертация валют и учёт личных активов в Telegram**

Koopeika объединяет конвертацию Telegram Stars, криптовалют и фиатных валют с учётом личных активов. Собирайте записи в разных валютах, а бот пересчитает их в любую удобную для вас валюту из поддерживаемых и покажет общий баланс. Управление доступно через кнопки прямо в чате.

## 💎 Уникальные возможности конвертации

- **Telegram Stars → любая поддерживаемая валюта.** Узнайте стоимость звёзд в рублях, долларах, евро и других доступных валютах, а также в криптовалюте.
- **Любая поддерживаемая криптовалюта → любая поддерживаемая валюта.** Пересчитывайте стоимость монет в нужную фиатную валюту или другую криптовалюту.
- **Записи в разных валютах → единый баланс.** Добавляйте суммы в рублях, долларах, евро, криптовалютах и Stars. Бот объединит их стоимость в выбранной валюте отображения. Меняйте её в профиле, чтобы видеть все активы в удобной единице расчёта.

Например, можно вести записи в RUB, USD и BTC, а общий баланс смотреть в EUR — без ручного пересчёта каждой записи.

## ✨ Возможности

| Раздел | Что умеет бот |
| --- | --- |
| 🏪 Конвертация | Stars и любая поддерживаемая криптовалюта в любую доступную валюту |
| 💰 Баланс | Автоматический пересчёт записей из разных валют в одну выбранную валюту |
| 💸 Активы | Записи о пополнениях и списаниях в разных валютах с комментариями |
| 📔 Транзакции | История операций с пагинацией, редактирование и удаление записей |
| 📖 Список валют | Справочная информация о валютах, криптовалютах и Stars |
| 👤 Профиль | Выбор валюты, часового пояса, точности сумм и стиля обозначений |
| ⭐ Premium | Подписка через Telegram Stars, расширение списка криптовалют и лимитов |

В базовом списке криптовалют предусмотрены **BTC, ETH, SOL и TON**. Дополнительные монеты загружаются из API; в настройках Premium доступны списки на 16, 28, 36 и 48 монет.

Конвертация рассчитывает эквивалент суммы. Учёт активов основан на введённых пользователем операциях. Курсы покупки и продажи Stars заданы в коде и являются приблизительными.

## 🤖 Как пользоваться

1. Откройте [@koopeika_bot](https://t.me/koopeika_bot) и отправьте `/start`.
2. В **Профиле** выберите валюту для отображения баланса и часовой пояс.
3. Через **Активы** внесите пополнение или списание.
4. Смотрите итог в **Балансе**, а записи — в **Транзакциях**.
5. Для пересчёта суммы откройте **Конвертацию**.

Команда `/info` показывает пользовательское соглашение и условия подписки.

## 🛠 Технологии

- **Python 3.12**, **aiogram 3** — асинхронный Telegram-бот с long polling и FSM.
- **PostgreSQL**, **SQLAlchemy 2**, **asyncpg** — хранение пользователей, операций и платежей.
- **aiohttp**, **requests** — получение курсов из внешних API.
- **APScheduler 4.0.0a6** — обновление курсов и очистка неактивных профилей.
- **python-dotenv** — загрузка конфигурации из `.env`.
- **Docker**, **Docker Compose**, **GitLab CI** — контейнеризация и описанный в репозитории процесс сборки.

Версии и ограничения зависимостей перечислены в [requirements.txt](requirements.txt).

## 🔄 Фоновые задачи

| Задача | Расписание |
| --- | --- |
| Обновление фиатных курсов | Ежедневно в 00:00 по часовому поясу планировщика |
| Обновление криптовалютных курсов | Каждые 5 минут |
| Очистка неактивных профилей в памяти | Каждые 10 минут; тайм-аут профиля — 1 час |

Фиатные курсы и список криптовалют также загружаются при импорте конфигурации. Доступ к API необходим уже на этапе запуска. Очистка профилей удаляет временное состояние из памяти; история операций хранится в PostgreSQL.

```text
│   ├── main.py              # Точка входа, polling и планировщик
│   ├── assets/              # Пополнения и списания
│   ├── balance/             # Баланс активов
│   ├── base/                # Стартовое меню и команды
│   ├── config/              # Конфигурация и временные профили
│   ├── conversion/          # Конвертация сумм
│   ├── core/                # Роутеры и подключения к БД
│   ├── info/                # Справочник валют
│   ├── keyboards/           # Кнопки интерфейса
│   ├── middlewares/         # Антифлуд и проверка профиля
│   ├── models/              # Модели SQLAlchemy
│   ├── payments/            # Оплата Premium через Stars
│   ├── rates/               # Получение курсов
│   ├── schedulers/          # Фоновые задачи
│   ├── settings/            # Пользовательские настройки
│   ├── states/              # Состояния FSM
│   ├── tasks/               # Логирование и обработка чисел
│   ├── transactions/        # История и изменение операций
│   ├── user_profile/        # Интерфейс профиля
│   ├── users/               # Работа с пользователями
│   └── utils/               # Вспомогательные функции
├── requirements.txt
├── Dockerfile
├── docker-compose.yml
└── .gitlab-ci.yml
```
